# BrokerHub AI Organization

## Mission

Build an autonomous AI organization that continuously processes input,
understands information, produces output, detects failures, repairs them,
retests the result, and stops only when the required quality standard is met.

## Primary Quality Objective

TRUE FIELD COMPLETENESS

The system must capture every meaningful fact contained in the original
input, map each fact to the correct field or semantic representation,
preserve unmapped information, and never invent information.

## Core Principle

RAW INPUT -> UNDERSTAND -> EXTRACT -> MAP -> TEST -> QC -> REPAIR -> RETEST -> OUTPUT

A failed result is not the end of the task.
A failed result becomes a new work item for root-cause analysis and repair.

## Non-Negotiable Rules

1. Raw input must remain preserved.
2. No agent may invent facts.
3. Every meaningful fact must be mapped to a field or semantic representation.
4. Unknown information must remain unknown.
5. Unmapped facts must not be silently discarded.
6. Changes must be regression tested.
7. Critical regression blocks release.
8. QC is the release gate.
9. Agents must work within their defined permissions.
10. Human approval is required for decisions outside the defined authority.
